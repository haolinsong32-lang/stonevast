## What is StoneVast?

StoneVast is a set of tools built by a miner, for miners. After running a 4070 laptop for 7 days straight and losing $0.11 to electricity, we built the calculator that tells 70% of people **NOT** to start mining.

石广是矿工为矿工打造的工具集。在 4070 笔记本连续挖矿 7 天、倒贴电费之后，我们做了一个会告诉你「别挖」的计算器。

## Tools

- **Break-even Calculator** — Input your GPU and electricity rate. Get a GO / NO-GO verdict in red if the math doesn't work.
- **Real-time Dashboard** — Hashrate, power draw, daily net, cumulative earnings. All live, all verifiable.
- **APR vs APY Explainer** — Because most people in crypto still confuse these and lose money because of it.
