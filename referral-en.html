05 BIND · How downstream nodes bind a referral code

1The downstream user opens the promotion link (recording the code), or simply notes the code down.
2Append the referral code suffix to the worker name in your mining software, e.g. myrig.svref-SV-XXXXXXXX (works for Pearl/IRON miners).
3Register your mining address + referral code in the official Telegram group. Rebates start once the settlement engine writes the invited_by relation into users.json.
4On each downstream pool settlement event, the system generates rebate records automatically; rebates are sent to upstream registered wallet addresses on the settlement cycle.
Settlement engine rule version: infinite-halving-v2-alpha (unlimited multi-tier halving; the engine settles automatically along the invited_by chain, and binding relations are verified via Telegram registration).

06 GUARANTEE · Downstream keeps a positive daily net

Rebates are split only from net production actually settled by the pool — never from a node's principal, electricity cost or unsettled balance. The sum of all tier shares is always below the total production, so the producing node's daily retained share is always positive — the more you produce, the more you keep.

Chain top attribution: the official primary code SV-STONEVAST maps to the project's highest Alpha node — every new node joining through official channels is attached under Alpha, and all tier shares flow up to the chain top.
