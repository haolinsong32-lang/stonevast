本文说明登记、无限级减半费率、节点令牌、心跳、公开钱包与关系查询契约。节点功能不是免费测算、官方下载或挖矿启动的必经步骤。

前往节点登记独立查看实际到账
DOCUMENT STATUS / 2026-11-18 · RULE / infinite-halving-v1 · 实际响应以服务端当前版本为准

先读边界

登记不产生收入，分账权益不等于实际付款。无限级整数分账与冲正核心已实现，但生产结算仍未开启：必须先建立可信的「链上事件 → 产币节点 UID」映射。没有真实净产出、最终确认事件、有效关系或公开地址，就不会形成可付款权益。
可以记录
节点 UID、无限邀请关系、减半费率资格、公开 IRON 地址、心跳状态与整数分账流水。
不要提交
助记词、私钥、钱包密码、交易所 API Key、身份证件或任何付款授权信息。

标识与状态

字段形式工程含义
keySV-XXXXXXXX登记或激活使用的单次凭证；初始为 unused，成功后转为 used。
invite_codeN-XXXXXXXX建立不限层级的邀请关系与分成资格；邀请本身不保证产生收入。
uid服务端返回的节点标识用于查询与记录；不是身份密钥、钱包所有权证明或付款授权。
nodeTokensvn_...注册或管理补发时仅返回一次；服务端只保存 SHA-256 哈希，用于心跳认证。
address公开 IRON 地址作为公开分账地址记录；不代表托管、地址所有权证明或已经付款。
last_heartbeat_atUnix 秒时间戳独立节点心跳证据；最近 300 秒内才计为活跃，不能用 PV、UV 或 IP 冒充。

卡密字符集避免使用易混淆的 0 / O / 1 / I。已经使用的卡密不能再次登记或激活。

登记流程

  1. 前端读取输入：卡密必填，邀请码可选；首页将两者转为大写后发送。
  2. 服务端校验：检查卡密是否有效且未使用；如提供邀请码，再记录对应关系。
  3. 成功返回：返回节点记录与一次性的 nodeToken；首页只持久保存 UID，不保存节点令牌。
  4. 立即保存：刷新或关闭后不能再次获取令牌；丢失只能由管理员补发，补发后旧令牌立即失效。
  5. 结果边界：登记建立关系与分成资格，但不创建收入、实际付款或任何链上交易。

激活与卡密状态

POST /api/v1/activate
Content-Type: application/json

{
  "key": "SV-XXXXXXXX",
  "uid": "服务端返回的节点标识"
}

激活表示把有效卡密用于已有节点记录，并推进卡密状态。创世角色只影响 L1 直推费率，不保证收益或付款，也不代表恢复 Pro 收款。若当前服务端未开放该操作，应以实际错误响应为准，不由前端伪造成功状态。

公开钱包地址记录

POST /api/v1/node/wallet
Content-Type: application/json

{
  "uid": "服务端返回的节点标识",
  "address": "公开 IRON 地址"
}
  1. 只填公开地址：首页进行格式检查后发送，不接受助记词或私钥。
  2. 没有所有权签名：该记录不能单独证明地址归属，也不能作为转账或扣款授权。
  3. 只记录，不等于付款：保存成功只表示地址记录更新，不产生收益、欠款、付款或提现；后续分账权益也必须单独核验，不能写成已到账。
修改公开地址前应人工核对。不要把截图、钱包导出或聊天记录中的私密信息粘贴到该输入框。

关系查询接口

请求用途解释边界
GET /api/v1/node/my?uid=sv_xxx读取当前节点、公开地址记录及关系统计。首页只据此渲染节点记录，不渲染应付款。
GET /api/v1/node/downline?uid=sv_xxx&depth=3&offset=0&limit=50读取下级关系树；depth 只控制本次展示深度，不限制实际关系或分成资格。offset/limit 控制分页，limit 为 1–200；人数和层级不代表计酬或实际产出。
GET /api/v1/node/lineage?uid=sv_xxx&offset=0&limit=50分页读取完整上级关系链，不在第 3 层截断。分页只影响展示，不影响结算关系深度；关系字段也不是收益或付款凭证。
GET /api/v1/node/lookup?code=N-XXXX按邀请码查询对应节点关系。不用于证明钱包所有权、实际到账或应付金额。

查询参数必须 URL 编码。具体字段、可用深度和错误码以服务端当前响应为准；调用方不得用缺失字段补造收入或零值。

节点心跳与真实状态

POST /api/v1/node/heartbeat
Content-Type: application/json

{
  "uid": "sv_xxx",
  "token": "svn_..."
}

GET /api/v1/node/stats
  1. 独立认证：矿工端使用注册或管理补发时获得的节点令牌，建议每 60 秒上报一次；令牌不得写入网页本地存储或公开日志。
  2. 活跃口径：最近 300 秒内有通过认证的心跳才计为活跃；失联、从未上报与离线分别统计。
  3. 不可混用：registeredNodes 是注册节点数，activeNodes 是活跃节点数，staleNodes 是曾上报但已失联数，neverReportedNodes 是从未上报数，offlineNodes 是当前非活跃数；PV、UV 和独立 IP 均不能冒充节点。

管理补发接口需要服务端配置的 X-Admin-Token，补发后旧节点令牌立即失效。管理令牌只应由管理员保管，不放入前端。

响应与失败处理

情况前端应如何呈现禁止行为
{ "ok": true, ... }仅展示服务端实际返回的节点、地址、资格或权益状态。不得把分成资格、应计未付权益或关系记录写成已付款。
{ "ok": false, "err": "..." }展示错误并保留用户重新核对的机会。不得把失败改写成已登记、已绑定或已付款。
超时、断网、非 JSON 响应显示网络或格式错误，状态保持未知。不得默认成功、自动重试写操作或重复提交卡密。

UID 缓存在当前浏览器，用于读取既有节点记录；清理浏览器数据后可能无法自动恢复页面展示。它不是安全凭证，不应替代正式身份认证。

与公开账本的隔离

实际到账只能由符合口径的已确认矿池付款和对应交易证据支持。无限级分账核心按最终确认的真实净产出计算整数权益并支持冲正，但权益、历史快照、矿池未付余额、测算结果、节点人数、邀请关系与公开地址记录均不属于实际到账。

当前服务状态

  • 节点登记：可选的记录功能，不是下载或运行挖矿软件的前提。
  • 生产结算：整数分账与冲正核心已实现，但可信的「链上事件 → 产币节点 UID」生产映射尚未配置，因此未开启生产分账；仅凭 UID、关系或公开地址不得自动打款。
  • Pro：收款与自助激活暂停，不提供价格、付款或续费入口。
  • 安全：任何自称官方的人都不会因登记、激活或支持而索取助记词、私钥或钱包密码。
