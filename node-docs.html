节点登记是记录，不是结算系统

本文说明首页现有登记、激活、公开钱包记录和关系查询契约。节点功能不是免费测算、官方下载或挖矿启动的必经步骤。

DOCUMENT STATUS / 2026-11-17 · 接口路径沿用现有前端 · 实际响应以服务端当前版本为准

先读边界

关系记录不等于收益、应付款或自动结算。登记、激活、邀请关系和公开钱包地址都不会触发挖矿产出、链上转账或提现；节点接口也不是实际到账数据的来源。
可以记录
登记卡密状态、节点 UID、可选邀请关系、公开 IRON 地址及关系查询结果。
不要提交
助记词、私钥、钱包密码、交易所 API Key、身份证件或任何付款授权信息。

标识与状态

字段形式工程含义
keySV-XXXXXXXX登记或激活使用的单次凭证；初始为 unused，成功后转为 used。
invite_codeN-XXXXXXXX可选关系标识；只用于建立节点关系，不表示收益或付款资格。
uid服务端返回的节点标识用于查询与记录；不是身份密钥、钱包所有权证明或付款授权。
address公开 IRON 地址仅保存公开地址记录；当前流程不应被解释为托管、收款或自动打款配置。

卡密字符集避免使用易混淆的 0 / O / 1 / I。已经使用的卡密不能再次登记或激活。

登记流程

  1. 前端读取输入：卡密必填，邀请码可选；首页将两者转为大写后发送。
  2. 服务端校验：检查卡密是否有效且未使用；如提供邀请码，再记录对应关系。
  3. 成功返回：返回节点记录，首页保存其中的 uid 并展示 invite_code。
  4. 结果边界：只完成关系登记，不创建收益、应付款、结算单或任何链上交易。
POST /api/v1/register
Content-Type: application/json

{
  "key": "SV-XXXXXXXX",
  "invite_code": "N-XXXXXXXX"
}

首页成功分支读取 d.ok 与 d.user；失败时展示服务端返回的 d.err，网络失败不会伪报成功。

激活与卡密状态

POST /api/v1/activate
Content-Type: application/json

{
  "key": "SV-XXXXXXXX",
  "uid": "服务端返回的节点标识"
}

激活表示把有效卡密用于已有节点记录，并推进卡密状态。它不代表购买 Pro、获得付款资格或启动自动结算。若当前服务端未开放该操作，应以实际错误响应为准，不由前端伪造成功状态。

公开钱包地址记录

POST /api/v1/node/wallet
Content-Type: application/json

{
  "uid": "服务端返回的节点标识",
  "address": "公开 IRON 地址"
}
  1. 只填公开地址：首页进行格式检查后发送，不接受助记词或私钥。
  2. 没有所有权签名：该记录不能单独证明地址归属，也不能作为转账或扣款授权。
  3. 没有结算副作用：保存成功只表示地址记录更新，不产生收益、欠款、付款或提现。
修改公开地址前应人工核对。不要把截图、钱包导出或聊天记录中的私密信息粘贴到该输入框。

关系查询接口

请求用途解释边界
GET /api/v1/node/my?uid=sv_xxx读取当前节点、公开地址记录及关系统计。首页只据此渲染节点记录，不渲染应付款。
GET /api/v1/node/downline?uid=sv_xxx&depth=3读取下级关系树；既有文档约定最多查询 10 层。人数和层级只描述关系，不代表计酬或实际产出。
GET /api/v1/node/lineage?uid=sv_xxx读取上级关系链。历史字段即使存在，也不得解释为收益或结算凭证。
GET /api/v1/node/lookup?code=N-XXXX按邀请码查询对应节点关系。不用于证明钱包所有权、实际到账或应付金额。

查询参数必须 URL 编码。具体字段、可用深度和错误码以服务端当前响应为准；调用方不得用缺失字段补造收入或零值。

响应与失败处理

情况前端应如何呈现禁止行为
{ "ok": true, ... }仅展示服务端实际返回的节点或地址记录。不得附带收益、返佣、结算成功等暗示。
{ "ok": false, "err": "..." }展示错误并保留用户重新核对的机会。不得把失败改写成已登记、已绑定或已付款。
超时、断网、非 JSON 响应显示网络或格式错误，状态保持未知。不得默认成功、自动重试写操作或重复提交卡密。

UID 缓存在当前浏览器，用于读取既有节点记录；清理浏览器数据后可能无法自动恢复页面展示。它不是安全凭证，不应替代正式身份认证。

与公开账本的隔离

实际到账只能由符合口径的已确认矿池付款和对应交易证据支持。历史快照、矿池未付余额、测算结果、节点人数、邀请关系与公开地址记录均不属于该口径。

当前服务状态

  • 节点登记：可选的记录功能，不是下载或运行挖矿软件的前提。
  • 自动结算：未由上述节点接口提供；仅凭 UID 或公开地址不得自动打款。
  • Pro：收款与自助激活暂停，不提供价格、付款或续费入口。
  • 安全：任何自称官方的人都不会因登记、激活或支持而索取助记词、私钥或钱包密码。
